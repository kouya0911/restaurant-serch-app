# 友達向け：使い方（お願い）

デモ用のアプリを、ピッチまでの数日間、実際に使ってみてほしい。お店に「行く予定」と「行ったよ」を記録すると、お店側の画面に人数だけが表示される（名前は出ない）。

1. `<アプリのURL>` を開いて、Google アカウントでログインする。
2. 行きたいお店を探して、お店の詳細で「行く日をカレンダーに追加」→ 行く日を選んで「登録する」。
3. お店に行った日に、左上のメニュー（≡）→「これから行く」→ その予定の「行ったよ」→ 認証コード `<コード>` を入力して「認証する」。
4. 「来店を記録しました」のあとに、そのままレビュー（星 1〜5 と、任意でひとこと 200 字まで）を書ける。あとで書くときは、左上のメニュー（≡）→「レビューを書く」から。星とひとことはお店の画面に表示される（名前は出ない）。
5. うまくいかないときや気になったことは、なんでも `<連絡先>` に教えてほしい。

※ 「行ったよ」が使えるのは、デモ対象のお店だけ（`<対象のお店の名前>`）。認証できるのは、予定の日当日のみ。レビューは予定 1 件につき 1 回で、あとから直したり消したりはできない。
